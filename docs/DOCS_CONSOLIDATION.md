## 🔄 维护建议

### 更新优先级

1. **AI_AGENT_GUIDE.md** - 最高优先级
   - 任何重大变更都要更新
   - 保持"当前状态"章节最新
   - 更新"下一步工作"清单

2. **DOCS_INDEX.md** - 高优先级
   - 添加新文档时更新
   - 更新文档状态
   - 保持链接有效

3. **README.md** - 高优先级
   - 保持项目介绍最新
   - 更新快速开始指南

4. **专题文档** - 按需更新
   - 相关功能变更时更新
   - 保持技术准确性

### 更新流程

```
1. 做出代码变更
2. 更新 AI_AGENT_GUIDE.md 相关章节
3. 如有必要，更新专题文档
4. 更新 DOCS_INDEX.md 的状态
5. 提交时注明文档更新
```
